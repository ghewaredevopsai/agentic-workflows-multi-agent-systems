Module 8 — Safety & Guardrails

Day 3 hands-on · five labs, intermediate to advanced
One case file throughout · self-checked · solutions provided

How these labs work. Fill every BLANK, then run the Self-check cell under each section. It prints [PASS], [FAIL] or [TODO], and the last cell prints your Score.

Your score never depends on a live model. Graded cells are plain Python. Cells marked Run it for real do call the sandbox model — if it is unreachable they print how to fix it rather than crashing, so Run All is always safe on an untouched notebook.

Controls, not measurements. A measurement tells you how often something happens; a control decides what happens. Everything graded here is stdlib and runs offline, because a control you can only test by running the model is not much of a control. The Run it for real cells put the sandbox model on the other side — as a detector, as a source of malformed output, and as your red-team opponent.

Lab 8.4 — Blast Radius and Tool Governance

“Is it secure?” has no answer. “What could an attacker do with it?” is a list you can shorten.

  • Compute blast radius, and shrink it with least privilege
  • Find out what actually breaks when you do
  • Produce a grant a reviewer can approve in a minute
