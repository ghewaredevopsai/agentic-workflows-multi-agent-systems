Module 2 — Agentic Planning & Reasoning

Day 1 hands-on · five labs, intermediate to advanced
One case file throughout · self-checked · solutions provided

How these labs work. Fill every BLANK, then run the Self-check cell under each section. It prints [PASS], [FAIL] or [TODO], and the last cell prints a Self-check tally.

You write real LangChain and LangGraph code in every lab. The Self-check cells assert on the objects you build — a bound tool, a compiled graph, a validated schema — so they are deterministic and do not need the model. Cells marked Run it for real put your code in front of the sandbox model; that is the part worth watching. Run All is always safe on an untouched notebook, and the score line is feedback, not a grade.

The same case file as Module 1 — payment exceptions on a small synthetic ledger. Module 1 asked whether to build an agent; these labs ask how it should think.

Lab 2.2 — ReAct, and the Parser You Do Not Have to Write

Write the ReAct parser, break it, then meet the version where the argument is schema-checked.

  • Do the same job with bind_tools, where the argument is schema-checked

Lab 2.3 — Sub-goals That Finish, and Knowing When to Re-plan

The failure that looks like bad luck, and the one that looks like a reasoning bug.

  • Reject sub-goals no agent could ever call finished

Lab 2.4 — Branch, Score, Prune: and When to Stop Reflecting

Branch concurrently, score with a structured judge, and stop reflecting when it stops paying.

  • Generate several candidate actions concurrently with .batch()
  • Score them with a structured judge instead of reading them yourself
  • Prune, and look at what you threw away
  • Build a reflection loop that stops when it stops improving
