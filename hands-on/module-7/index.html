Module 7 — Multi-Agent System Evaluation

Day 3 hands-on · two labs
One case file throughout · self-checked · solutions provided

How these labs work. Fill every BLANK, then run the Self-check cell under each section. It prints [PASS], [FAIL] or [TODO], and the last cell prints your Score.

Self-checks assert on objects, not on scores. You build the real thing — a create_agent under test, a typed Verdict, a BaseCallbackHandler that traces a run — and the checks run against those objects and against runs recorded in the notebook. That is deterministic and needs no endpoint. Cells marked Run it for real do call the sandbox model; they are never scored, because scoring a single live run is the mistake Lab 7.1 exists to teach.

Every blank asks a decision. The mechanics are given. What is left blank is the thing only understanding answers: which field a score can honestly be built on, which failure is disqualifying rather than merely low-scoring, which of two numbers goes in front of the person who owns the budget.

Nothing depends on a tracing backend. No graded cell touches Langfuse. The Langfuse cells print the field mapping and return when it is not configured, so an outage costs the demo and never a score.

Lab 7.1 — Locating the Failing Step

Six real runs captured from the deployed app. Four are wrong, each at a different step, and every one of the six printed QA PASS. Say where, from the evidence.

  • Read one run out of an audit trail that spans a whole conversation
  • Walk a fixed ladder of eight checks, cheapest first, over the six runs
  • Tell apart two runs that look equally wrong and failed at different steps
  • Work out what each failure cost, and which one to escalate
  • Break one step of your own deployment, locate it, and fix just that step

Lab 7.2 — Prompt Versioning with Langfuse

A prompt in your code is a deploy. A prompt in Langfuse is a config change — and a bad one is a thirty-second rollback instead of a redeploy.

  • Store a prompt in Langfuse and change it without touching your code
  • Move a production label between versions — and roll it back
  • Link a model call to the exact prompt version that produced it
  • Keep serving when Langfuse is unreachable, with fallback=
