Module 6 — Agentic RAG

Day 2 hands-on · five labs, intermediate to advanced
One case file throughout · self-checked · solutions provided

How these labs work. Fill every BLANK, then run the Self-check cell under each section. It prints [PASS], [FAIL] or [TODO], and the last cell prints your Score.

Your score never depends on a live model. Graded cells are plain Python. Cells marked Run it for real do call the sandbox model — if it is unreachable they print how to fix it rather than crashing, so Run All is always safe on an untouched notebook.

A corpus, not a ledger — two short operating documents the agent has to go and read. The scoring function is term overlap rather than an embedding, so every check is exact and offline; chunking, floors, filters, citations and the metrics are identical whatever computes the similarity. Lab 6.1's Run it for real puts the same corpus into ChromaDB with a real embedding model so you can see where semantics win — that first run downloads about 80 MB.

Lab 6.1 — A Retriever You Can Inspect

Cut a document two ways and watch one of them put an answer permanently out of reach.

  • Chunk on meaning, so a rule keeps the exception that qualifies it
  • Watch top-k return four confident chunks from a corpus that has nothing
  • Build the score floor that makes an empty result possible
  • Scope with metadata — a filter is also an access control

Lab 6.2 — Retrieval as a Tool the Agent Chooses

Lab 6.3 — Adequacy, Re-querying and Multi-Hop

The loop a pipeline cannot have: judge your own retrieval, then ask again with what it taught you.

  • An adequacy test that can actually say no
  • Follow a chain of reason codes across three hops
  • A hop budget, a repeat detector, and ‘I could not find it’ as a real outcome

Lab 6.4 — Citations Bound to Spans, and Refusing

A citation that names a document proves nothing. A span is checkable by string comparison.

  • Bind each claim to the exact characters that support it
  • Drop a claim that cannot name its source, before it ships
  • Refuse when the corpus cannot answer — and say what is missing

Lab 6.5 — Challenge: Score the Two Halves Apart

A right answer from the wrong evidence passes every demo you will ever run.

  • Label an eval set, then measure recall@k and precision@k
  • Measure faithfulness and answer relevance with no labels at all
  • Put a run in the 2×2 and read off which half to fix
  • Meet the limits of an exact-match faithfulness score — on purpose
