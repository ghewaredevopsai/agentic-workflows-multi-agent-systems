Module 6 — Agentic RAG

Day 2 hands-on · eight labs, beginner to advanced
One handbook corpus throughout · self-checked · solutions provided

How these labs work. Fill every BLANK, then run the Self-check cell under each section. It prints [PASS], [FAIL] or [TODO], and the last cell prints your Score.

Self-checks assert on the objects you built — a chunked Document, a Chroma collection, a retriever, an LCEL chain. None of that needs the gateway, so your score never depends on a live model. Cells marked Run it for real do call the sandbox model — if it is unreachable they print how to fix it rather than crashing, so Run All is always safe on an untouched notebook.

A company handbook, and two different models. The corpus is a set of short policy passages, each carrying a category, a source file and a page — metadata is not decoration, it is the half of retrieval that is exact. Retrieval runs on a real Chroma collection embedded by all-MiniLM-L6-v2, which runs on your own pod: no gateway, no key, nothing billed. The chat model is the one on the gateway. Keeping those two straight is most of this module.

Lab 6.2 — Understanding Embeddings

Two questions with no words in common, and a number that says they mean the same thing.

  • Turn a sentence into 384 numbers and look at them
  • Predict which pair scores highest, then measure — the gap is the lesson
  • Choose between embed_query and embed_documents, and know why there are two
  • Build a search engine in fifteen lines, which is all a vector store does

Lab 6.7 — RAG with Citations

A citation is a binding, not a footnote — the model can only name what it was given.

  • Put the source and page into the context, because nothing else can produce them
  • Ask for a fixed citation format, not just “cite your sources”
  • Build a category-scoped assistant from a filtered retriever
  • Check that every source it named was really in the context

Lab 6.8 — Challenge: a Handbook Q&A Bot

Every stage, yours to assemble — and every number, yours to pick.
