Module 5 — Multi-Agent Collaboration & Orchestration

Day 2 hands-on · three systems, intermediate to advanced
One system per lab · self-checked · solutions provided

How these labs work. Fill every BLANK, then run the Self-check cell under each section. It prints [PASS], [FAIL] or [TODO], and the last cell prints your Score.

You write real LangGraph code in every lab. The Self-check cells assert on the objects you build — a compiled StateGraph, a declared reducer, a routing key — so they are deterministic and never need the model. Cells marked Run it for real do call the sandbox model; if it is unreachable they print how to fix it rather than crashing, so Run All is always safe on an untouched notebook.

Three systems, not three exercises. Each lab is one thing you would recognise in production, built end to end, with its own small case file: a support desk, a research brief, an incident responder. Every blank is a decision — which node, which key, which merge rule, which way out — not a Python puzzle.

Lab 5.1 — A Support Desk That Triages Itself

One queue in, three specialists behind it. A supervisor is a classifier, so score it like one.

  • Build the supervisor/worker graph with a real add_conditional_edges
  • Choose the fallback — every unrecognised ticket in the system lands there
  • Score the router on twelve labelled tickets, and set a bar before you look
  • Swap in a model-routed supervisor and score that on the same twelve

Lab 5.2 — A Research Brief Written by Several Agents at Once

Fanning out is easy. The merge is the design — and the un-annotated version fails in front of you.

  • Fan out to three researchers that finish in a single superstep
  • Watch the un-annotated key raise InvalidUpdateError, then write the reducer
  • Resolve two contradicting sources by authority, not by vote
  • Carry provenance into the report, so every line can be traced
3 blanks · 11 checks · solution: solutions/lab-5-02-parallel-research-brief.ipynb
35 minAdvanced

Lab 5.3 — An Incident Responder That Knows When to Stop

A cycle is an edge pointing backwards. What makes it safe is the budget, and where the budget lives.

  • Route the three ways out of verify — one of them is the infinite loop
  • Point the retry edge at the right node, and pay for triage once instead of every attempt
  • Prove a never-healing incident terminates, rather than hoping it does
  • Write the handoff an on-call human can act on at 3am
