Module 5 — Multi-Agent Collaboration & Orchestration

Day 2 hands-on · five labs, intermediate to advanced
One case file throughout · self-checked · solutions provided

How these labs work. Fill every BLANK, then run the Self-check cell under each section. It prints [PASS], [FAIL] or [TODO], and the last cell prints your Score.

Your score never depends on a live model. Graded cells are plain Python. Cells marked Run it for real do call the sandbox model — if it is unreachable they print how to fix it rather than crashing, so Run All is always safe on an untouched notebook.

The same case file throughout — payment exceptions on a small synthetic ledger, now worked by several specialists at once. The specialists are deterministic stand-ins, so a graph's structure and its cost can be graded exactly; the Run it for real cells put the sandbox model behind the same interfaces.

Lab 5.1 — The Supervisor Is a Router

A supervisor picks a worker the way an agent picks a tool. So measure it the same way.

  • Build a rule-based supervisor and score it honestly
  • Read the confusion table — every miss lands on the default
  • Price a misroute: everything downstream of it was wasted

Lab 5.4 — Human-in-the-Loop as an Orchestration Mechanism

Interrupt, approve, time out, escalate — all four are checkpointing with a person in it.

  • Stop before the irreversible node and checkpoint the evidence
  • Open the gate for a named human — an identity, not a boolean
  • Climb an escalation ladder that terminates
  • Prove the one property of a gate: at the gate, “no” is still free

Lab 5.5 — Challenge: The Scorecard

Not a graph — an argument about whether to build one, with numbers a risk owner can dispute.

  • State the ground truth before measuring anything
  • Score a single agent and a four-specialist graph on the same cases
  • Price both, including the context re-sent at every hop
  • Compute the breakeven — and let “don't” be a real answer
