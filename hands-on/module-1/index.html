Module 1 — Agents vs. Multi-Agent Systems

Day 1 hands-on · five labs, intermediate to advanced
One case file throughout · self-checked · solutions provided

How these labs work. Fill every ___, then run the Self-check cell under each section. It prints [PASS], [FAIL] or [TODO], and the last cell prints your Score.

Your score never depends on a live model. Graded cells are plain Python. Cells marked Run it for real do call the sandbox model — if it is unreachable they print how to fix it rather than crashing, so Run All is always safe on an untouched notebook.

One case runs through all five: payment exceptions on a small synthetic ledger. Each lab carries forward what the previous one built, so work them in order.

Lab 1.4 — One Agent or Three: Measuring the Coordination Tax

“We need multiple agents” is a hypothesis. This is how you test it.

  • Route work to specialist workers from a supervisor
  • Meter both designs identically — steps, estimated tokens, wall time
  • Score them on one eval set, and count the failure surface that grows fastest
