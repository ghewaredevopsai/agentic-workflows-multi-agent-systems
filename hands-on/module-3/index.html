Module 3 — LangGraph: Stateful Agent Workflows

Day 1 hands-on · eight labs, one concept each, intermediate to advanced
One case file throughout · the first four need no model · self-checked · solutions provided

How these labs work. Fill every BLANK, then run the Self-check cell under each section. It prints [PASS], [FAIL] or [TODO], and the last cell prints a Self-check tally.

You write real LangChain and LangGraph code in every lab. The Self-check cells assert on the objects you build — a bound tool, a compiled graph, a validated schema — so they are deterministic and do not need the model. Cells marked Run it for real put your code in front of the sandbox model; that is the part worth watching. Run All is always safe on an untouched notebook, and the score line is feedback, not a grade.

The same case file as Module 1 — payment exceptions on a small synthetic ledger. Modules 1 and 2 chose the shape and the thinking; these labs give both somewhere to live.

Lab 3.4 — State Reducers

Declare the merge rule once. Then run two nodes in one step and watch it matter.

  • Declare how a field combines, once, instead of hand-merging in every node
  • Decide which fields need a reducer and which should simply be replaced
  • Run two nodes in the same step and see what happens without one

Lab 3.5 — Cycles and Retry

A cycle is an edge pointing backwards. One comparison is what stops it being a hang.

  • Build a loop — an edge that points backwards, and nothing more exotic
  • Give it a step budget, because the runaway loop is Module 2's failure mode
  • Put the model inside one node and leave the control flow deterministic
