What this is. Everything below is a free, publicly available talk or tutorial that continues a specific part of the course. Each entry says which module it extends and why it is worth your time — nothing here is filler, and nothing repeats a lab you have already done.

How to use it. Work down the modules you want to go deeper on, not the list top to bottom. Conference talks (AI Engineer, Latent Space, Sequoia) carry the design judgement; vendor channels (LangChain, Anthropic, IBM, Google Cloud, Langfuse, Arize, Microsoft) carry the mechanics. Where a video predates the library version we used, the ideas still hold — check the current docs before copying code.

If you watch only six — in this order, about two hours total:
  1. How We Build Effective Agents — Barry Zhang, Anthropic (15:09): when not to build an agent.
  2. 12-Factor Agents — Dex Horthy (17:06): the reliability principles behind most of Day 1.
  3. Conceptual Guide: Multi Agent Architectures — LangChain (8:58): the pattern map for Module 5.

  5. How to Systematically Setup LLM Evals — Dave Ebbelaar (55:02): the discipline your capstone was graded on.

A note on shelf life. Agent tooling moves faster than video. Treat the conference talks as durable (the reasoning about architecture, cost and failure has not aged) and the code walkthroughs as illustrative — APIs such as create_agent, LangGraph checkpointers and the Langfuse SDK have all changed at least once since some of these were recorded. Verify against the current documentation before you copy a line into a repository.
